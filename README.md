# Wings Travel Agency — אתר עובד (Demo Mode)

זהו האתר האמיתי שלך, במצב **Demo Mode**: כל הזרימה עובדת מקצה לקצה עם נתונים
מדומים, עד שתחבר את מפתח ה-API של RateHawk.

## מה זה כולל

- שרת אמיתי (לא רק קבצי HTML) שמריץ את כל האתר
- מסד נתונים אמיתי בצד השרת (בקובץ `data/db.json`) לשמירת לקוחות והזמנות —
  לא localStorage, ולכן ההזמנות שלך יופיעו מכל דפדפן/מכשיר שמתחבר לשרת
- זרימת הזמנה מלאה: בית → חיפוש → תוצאות → מלון → בחירת חדר → checkout →
  יצירת הזמנה אמיתית → עמוד אישור → הופעה ב"ההזמנות שלי"
- תשלום מדומה בלבד — **אין חיוב אמיתי בשלב הזה**
- שכבת חיבור ל-RateHawk מוכנה ומופרדת, ממתינה למפתח ה-API שלך

## איך מריצים את זה (בלי צורך בידע בתכנות)

### שלב 1 — התקנת Node.js (פעם אחת בלבד)

אם אין לך Node.js מותקן במחשב:
1. גש ל-**https://nodejs.org**
2. הורד את הגרסה המומלצת ("LTS")
3. התקן כמו כל תוכנה רגילה (הבא, הבא, סיום)

### שלב 2 — הרצת השרת

1. פתח את תיקיית הפרויקט (`wings-app`)
2. פתח שם חלון טרמינל/Command Prompt:
   - **Windows**: לחיצה ימנית בתוך התיקייה → "Open in Terminal" (או שיפט + לחיצה ימנית → "פתח חלון PowerShell כאן")
   - **Mac**: פתח את אפליקציית Terminal, הקלד `cd ` (עם רווח), גרור את תיקיית הפרויקט לתוך החלון, הקש Enter
3. הקלד את הפקודה הבאה והקש Enter:

   ```
   node server.js
   ```

4. אתה אמור לראות הודעה כזו:

   ```
   Demo Mode: ON (using mock data)
   Wings Travel Agency server running at http://localhost:3000
   ```

5. פתח דפדפן וגלוש אל: **http://localhost:3000**

זהו — האתר רץ! אפשר לבצע הזמנה מדומה מלאה מקצה לקצה.

**חשוב:** כל עוד אתה רוצה שהאתר ירוץ, חלון הטרמינל הזה צריך להישאר פתוח. לסגירה, הקש `Ctrl+C` בתוך החלון.

## איך מחברים את RateHawk כשיגיע המפתח

1. העתק את `.env.example` לקובץ חדש בשם `.env` (באותה תיקייה)
2. מלא בו:
   ```
   RATEHAWK_API_KEY_ID=המפתח_שקיבלת
   RATEHAWK_API_KEY=המפתח_השני_שקיבלת
   ```
3. פתח את `server/providers/ratehawk.js` — יש שם 3 מקומות מסומנים `TODO`
   שצריך למלא לפי התיעוד הרשמי של RateHawk (שתקבל גישה אליו ברגע שהחשבון
   יאושר)
4. הפעל מחדש את השרת — Demo Mode יכבה אוטומטית, והאתר יתחיל להשתמש בנתונים
   האמיתיים מ-RateHawk

**חשוב:** שום קובץ אחר בפרויקט לא צריך להשתנות בשביל זה — זו בדיוק הסיבה
ששכבת ה-provider בנויה בנפרד.

## בעיות נפוצות

**"command not found: node"** — Node.js לא מותקן, חזור לשלב 1.

**"port 3000 already in use"** — שרת אחר כבר רץ על אותה כתובת. סגור אותו,
או שנה את השורה `PORT=3000` בקובץ `.env` למספר אחר (למשל 3001).

**רוצה למחוק את כל ההזמנות ולהתחיל מחדש?** מחק את התוכן של
`data/db.json` והחלף אותו ב-`{"customers": [], "bookings": []}`
